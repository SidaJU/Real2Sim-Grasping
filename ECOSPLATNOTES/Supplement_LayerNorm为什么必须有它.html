内容：问题根源 → 同一例子「不加 LN」与「加 LN」的完整数值对照 → 仿射还原 γ/β → 为什么是 Pre-LN → 回到源码
先看结论（后面全部是它的证据）

残差连接是加法，每过一层，token 向量的量级就会往上堆一点。 而 attention 里 scores = q · k 是两个这样的向量相乘 —— 量级放大 k 倍，scores 就放大 k² 倍（平方级）。 跑满 24 层后：不加 LN 的 scores 涨到 9.3 × 10²⁷，注意力彻底坍缩成「只盯一个 token」； 加了 LN 则稳定在 2.37 → 2.53，几乎纹丝不动。

1. 问题从哪来：残差是加法，量级只增不减

Chapter 02 的例子里，token1 在一个 Block 中的变化（原始数值）：

输入              [1,    0,    0,    0   ]
+ 注意力输出      + [1.4,  0.4,  0.2,  0.0]   →  [2.4,  0.4,  0.2,  0.0]
+ MLP 输出        + [0.25, 0.10, -0.15, 0.30] →  [2.65, 0.50, 0.05, 0.30]

一个 Block 就加了两次。除非每次加的量恰好正负抵消，否则向量的量级只会往上走。 EcoSplat 的编码器有 24 个 Block（backbone_croco_multiview.py:22 'enc_depth': 24），一共加 48 次。

1.1 为什么「量级变大」会致命

关键在于 attention 内部：

scores = q · k  /  √d
  • x 的量级放大 k 倍 → q、k 各自放大 k 倍
  • 点积是「逐个分量相乘再求和」→ scores 放大 k² 倍

而 softmax 对分差极度敏感（Chapter 02 已算过：分差 8 分 → 0.9957，分差 1 分 → 0.62）。 scores 一大，softmax 立刻「赢者通吃」，注意力表变成 [1, 0, 0] —— 每个 token 只盯着一个对象看，模型丧失了「综合多方信息」的能力。

一个真实会踩到的坑：float32 溢出

朴素 softmax 要算 e^score。float32 的上限约 3.4×10³⁸， 也就是 score 超过约 88 就会变成 inf，接着 inf/inf = NaN，整个网络直接报废。 下面你会看到：不加 LN 时，第 3 层的 max score 就到了 102 —— 已经越线。

4. 实验组：加上 LayerNorm（同一个例子）

4.1 第 1 层完整手算（Pre-LN）

【第 0 步】先对 x 做 LayerNorm（γ=1、β=0，即纯归一化）

  以 token1 = [1, 0, 0, 0] 为例，dim = 4：
    μ = (1+0+0+0)/4 = 0.25
    方差 = [(1-0.25)² + 3×(0-0.25)²] / 4 = (0.5625 + 3×0.0625)/4 = 0.1875
    σ = √0.1875 = 0.4330
    归一化 = [(1-0.25)/0.433, (0-0.25)/0.433, (0-0.25)/0.433, (0-0.25)/0.433]
           = [ 1.732, -0.577, -0.577, -0.577 ]
           校验：均值 ≈ 0，方差 ≈ 1 ✓

为什么加了 LN 还是「量级在涨」？

这是残差结构本身带来的，LN 管不了也不该管： 每层都在做 x ← x + 子层输出，子层输出量级大约恒定（因为输入被 LN 归一化了）， 所以 x 是线性增长（本例每层 +3.3 左右，24 层 → 72）。 真实 Transformer 也有这个现象，称为残差流的缓慢增长。

关键在于：进 attention 的永远是归一化后的 h，不是 x。 所以 scores 被死死钉在 2.37 ~ 2.53 —— 这才是 LN 真正守住的阵地。 线性增长（24 层 72 倍）无害；指数爆炸（24 层 10¹⁴ 倍）致命。

一句话总结这个对照

LN 不改变模型「能表达什么」，它只做一件事： 每到一个子层门口，把向量的尺度按回标准值，让后续的 Q/K/V 投影和点积始终在可控区间里工作。 没有它，网络会在几层之内把自己算崩。

6. 那 γ、β（仿射还原）又是干嘛的

y = γ ⊙ (x − μ) / σ + β

纯归一化有个副作用：它强行让每个 token「均值 0、方差 1」，等于把尺度信息全抹了。 可「这一维该多大、该往哪偏」本身可能就是网络想表达的东西。

所以补上 γ（缩放）、β（偏移），每个维度各一个，让网络自己学：

接第 4.1 节 token1 的归一化结果 [1.732, -0.577, -0.577, -0.577]，dim = 4：

  若 γ = [1,1,1,1]、β = [0,0,0,0]（初始状态）
    → [1.732, -0.577, -0.577, -0.577]          完全等于归一化结果（恒等）

  若网络学成 γ = [2, 1, 1, 1]、β = [0.1, 0, 0, 0]
    → [2×1.732 + 0.1, 1×(-0.577), 1×(-0.577), 1×(-0.577)]
    = [3.564, -0.577, -0.577, -0.577]          只有第 0 维被放大并偏移

  极端情况：γ_d = σ = 0.433、β_d = μ = 0.25
    → y_d = (x_d − 0.25)/0.433 × 0.433 + 0.25 = x_d
    → LN 被完整撤销，变回恒等（Chapter 02 就是挑了这组值让例子自洽）
所以 γ、β 的定位是

LN 给的是「规整好的标准尺度」，γ/β 把「要不要保留自己的尺度」的决定权还给网络。 它们是 nn.LayerNorm 里唯一的可学习参数（默认 elementwise_affine=True）， 初始化 γ=1、β=0 —— 训练刚开始时是恒等的，用不用、怎么用，让网络自己学。

注意 μ、σ 不是参数，是运行时对当前 token 当场算出来的统计量。

7. 为什么放在子层「前面」（Pre-LN）

src/model/encoder/backbone/croco/blocks.py · 第 128–130 行 
128      def forward(self, x, xpos):
129          x = x + self.drop_path(self.attn(self.norm1(x), xpos))
130          x = x + self.drop_path(self.mlp(self.norm2(x)))
131          return x
  • 每个子层拿到的输入一定是被规整过的（attention 拿 norm1(x)，MLP 拿 norm2(x₁)）。
  • 残差那条直连通路 x + ... 里的 x 原封不动 —— LN 不挡在梯度回传的主路上，深层训练才稳。 这就是 Pre-LN 取代 Post-LN（把 LN 放在残差之后）成为主流的原因，EcoSplat 用的也是 Pre-LN。
  • 一个 Block 里两个 LN：norm1 管 attention 前，norm2 管 MLP 前。

9. 小结

  1. LN 解决的是「量级漂移」：残差是加法，量级只增不减；而 scores 是 q·k，会平方级放大这个漂移。
  2. 它稳定的是每个 token 自己的尺度（最后那 1024 维），跟 batch、跟其他 token 都无关 —— 所以序列长度、分辨率、batch size 都能随便变。
  3. 守住的是 scores：本例 24 层后，不加 LN 到 9.3×10²⁷，加 LN 稳定在 2.53。
  4. γ、β 是「撤销权」：归一化不是强加的限制，网络可以学回自己的尺度。
  5. Pre-LN 不挡残差通路：子层前归一化，x 本身直连，深层梯度才稳。
  6. EcoSplat 里共 49 个 LayerNorm(1024)，10 万左右参数；patch embed 那个是 Identity，没生效。

自测

① 为什么量级放大 k 倍，scores 会放大 k² 倍？

因为 scores = q · k 是「对应分量相乘再求和」。 x 放大 k 倍后，q 和 k 都各放大 k 倍，每一项乘积就放大 k² 倍，求和后仍是 k² 倍。

② 加了 LN 之后，|x| 还是在涨（24 层到 72），这算失败吗？

不算。那是残差结构固有的线性增长，无害。 LN 守住的是「进子层的输入尺度」，所以 scores 恒定 —— 致命的是指数爆炸，不是线性增长。

③ 如果 γ、β 被学成 γ=σ、β=μ，会发生什么？

y = (x−μ)/σ × σ + μ = x，归一化被完整撤销，LN 变回恒等。 这说明 LN 是「可选的规整器」而不是硬性限制。
