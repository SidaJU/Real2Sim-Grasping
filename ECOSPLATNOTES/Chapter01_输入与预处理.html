Chapter 01 · 输入与预处理

EcoSplat 学习笔记 · 从「第一步」开始：网络到底吃进去什么、怎么加工、变成什么形状进入 Transformer
本篇覆盖：输入结构 → 归一化 → 切块成 token。（Transformer 内部留到 Ch.02）

1. 这一章回答什么

  1. 输入是什么——一个 batch 里有哪些张量、各是什么形状
  2. 为什么不需要位姿——代码里直接可以看到的证据
  3. 图像怎么归一化——一行公式，把像素搬到网络喜欢的区间
  4. 图像怎么变成 token——切块、投影、加上位置信息

2. 输入：一个 batch 里有什么

数据类型定义在 src/dataset/types.py：

class BatchedViews(TypedDict):        # 一组视角（context 或 target）
    image:      Float[Tensor, "batch view 3 height width"]
    intrinsics: Float[Tensor, "batch view 3 3"]
    extrinsics: Float[Tensor, "batch view 4 4"]
    near / far / index / overlap

class BatchedExample(TypedDict):      # 一个训练样本
    context: BatchedViews      # 输入视角（"已知"的几张图）
    target:  BatchedViews      # 目标视角（训练时要重建出来的）
    scene:   list[str]
关键证据：forward 里根本没取 extrinsics。 src/model/encoder/encoder_spfsplat.py:222-225： 
context_input = {
    "image":      normalize_image(context["image"]),
    "intrinsics": context["intrinsics"],
}
out = self.backbone(context_input)
喂给骨干的字典里只有图像和内参，位姿连取都没取。这就是「pose-free」最直接的证明—— 也解释了为什么它能用在没有相机标定位姿的场景（真实产线随手拍几张）。

3. 第一步处理：归一化

图像进网络前先做一次线性变换，定义在 src/dataset/shims/normalize_shim.py：

def normalize_image(tensor, mean=(0.5, 0.5, 0.5), std=(0.5, 0.5, 0.5)):
    return (tensor - mean) / std
x ← (x − 0.5) / 0.5 = 2x − 1

4. 第二步处理：切块，变成 token

Transformer 不吃像素网格，吃的是一串向量（token）。这一步由 patch_embed.py 的 PatchEmbedDust3R 完成，本质是：

# 核心两行（patch_embed.py:24-27）
x = self.proj(x)                       # 卷积：每个 16×16×3 的块 → 一个 1024 维向量
x = x.flatten(2).transpose(1, 2)       # 摊平成 [B, N, C]
x = self.norm(x)

4.1 跟着算一遍（用我们的实际配置）

量值怎么来的
输入图像256 × 256 × 3config 的 input_image_shape
patch 大小16 × 16patch_size
每行/每列块数256 ÷ 16 = 16整除（代码里有 assert）
patch 总数16 × 16 = 256
加 cls token256 + 1 = 257全局 token，汇总整图信息
每个 token 维度1024ViT-Large 的 enc_embed_dim
最终形状[b·v, 257, 1024]v 个视角各自 257 个 token
这解释了之前看到的一个数字。在 blocks.py 的注释里出现过 q: [1, 12, 257, 64]——那个 257 就是「256 个 patch + 1 个 cls」。 而 k,v: [1, 12, 514, 64] 里的 514 = 257 × 2，是两个视角的 token 拼在一起 （跨视角注意力的来源，Ch.03 展开）。

5. 小结：进入 Transformer 之前，数据变成了什么

一句话记住：几张普通照片 + 它们的内参 → 归一化到 [−1,1] → 每 16×16 像素压成一个 1024 维 token → 得到一串「带位置标记的视觉单词」，交给 Transformer 去读。

类比：把一张照片切成 256 块拼图，每块写一张 1024 维的「特征卡」，并在卡片角上标好它原来在第几行第几列。
