Lesson 06 · TSDF 融合与网格提取

项目：Real2Sim-Grasping（Isaac Sim → 3DGS → mesh → 抓取）
本篇回答：一堆软的高斯怎么变成仿真能用的实体网格—— TSDF 融合的原理、Marching Cubes 怎么抽出表面，以及我们项目里实际走了哪条路。
先更正一个事实。本篇讲 TSDF，但我们项目里 3DGS → mesh 目前实际用的是 Poisson 重建， 不是 TSDF——因为 ns-export tsdf 在这版 nerfstudio 上会崩 （报错 Could not find rgb in the model outputs，见 export_mesh.bat 注释）。 TSDF 目前只用在「真值深度对照组」gt_mesh_tsdf.obj。 两条路的对比见 §7。TSDF 仍值得先学：它是理解「表面从哪来」的基础，也是修好之后要走的正路。

1. 为什么非要这一步

3DGS 输出的高斯

一堆半透明椭球。擅长渲染新视角，但没有"表面"这个概念—— 夹爪抓不软的雾，物理引擎也做不了碰撞。

仿真需要的 mesh

三角网格：有明确的面、法线、内外之分。 能做碰撞检测、抓取接触点、质量与惯性计算——Isaac Sim 只认这个。

所以中间必须有一座桥：从"体积表示"里把"表面"抽出来。TSDF 就是最经典的那座桥。

为什么主力是 Poisson 而不是 TSDF？ export_mesh.bat 注释写明：ns-export tsdf 在这版 nerfstudio 会崩 （Could not find rgb in the model outputs），所以改成 ns-export gaussian-splat 导出高斯中心点云，再用 Open3D 的 Poisson 重建。

代价是：Poisson 用的是高斯中心，而高斯中心不等于表面（见 §8 的坑）， 所以脚本里要靠「低密度裁剪 + 最大连通分量」来补救，并用真值高度做尺度还原。

8. 参数与坑

8.1 两个关键参数

参数影响调错会怎样
体素边长精度 vs 内存（立方关系）太大 → 细节糊；太小 → 内存爆、表面碎
截断距离 t有效融合范围太小 → 表面断裂；太大 → 远处噪声混进来、物体变胖

8.2 三个必须知道的坑

坑 1：高斯中心 ≠ 表面

高斯是有体积的椭球，中心常在物体内部。直接拿中心点做表面重建会得到"内缩的壳"。 这正是 TSDF 用渲染深度（可见表面）而不是高斯中心的原因。

坑 2：背景会被一起重建

桌面、floaters 都会进体素场，变成 mesh 的一部分。 Poisson 路线靠 remove_statistical_outlier + 最大连通分量补救； TSDF 路线则要在融合前把深度图里的背景裁掉。

坑 3：视角没覆盖的地方会出洞

TSDF 只能重建至少被一张深度图看到的表面。相机拍不到的地方（物体底部贴桌面处） 永远是空的，Marching Cubes 在那里没有信息 → 破洞。这也是为什么我们的采集用了三个高度环。

9. 一句话总结

TSDF 做的事：让空间里每个小格子记住「我离表面多远、有多少张图给我投过票」， 然后把所有格子的答案平均起来，最后用 Marching Cubes 在"距离 = 0"的地方切出一张三角网。

它把一堆带噪声的深度观测变成了一个干净、水密、可直接进仿真的实体表面—— 这就是 3DGS 与 Isaac Sim 之间那座桥。
