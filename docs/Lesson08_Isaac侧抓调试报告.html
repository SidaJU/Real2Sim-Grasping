1. 与场景交互中的碰撞

1.1 概念解释

这里的碰撞，指机械臂或夹爪在接近物体过程中，与支柱、物体本身发生的非预期接触。 侧向夹取时，手指需要从物体边缘外侧伸入，因此接近路径很容易刮到物体顶面或撞到支柱。 这类碰撞会把物体推离支柱，导致后续无法夹取。

1.2 我们遇到的问题

现象

机械臂在 descend 阶段推进时，直接把物体顶开/撞倒。日志中出现过物体中心位移触发保护，也出现过接近高度偏高导致手指先刮到顶面。

1.3 最终修正

  • 缓速接近：目标点从预抓点滑动到抓点，用 APPROACH_STEPS = 180，不再一步冲进去。
  • 位移保护：接近途中若物体中心移动超过 5 mm，立即停止推进，避免把物体推离支柱。
  • 降低接近高度：SIDE_Z_FRAC = 0.35，让上手指和手腕从顶边下方经过，避免刮到顶部。

2. 接触

2.1 概念解释

接触指夹爪闭合时，指垫真正压住物体的上下表面，形成有效夹持。 关键难点是：控制器控制的是模型的左指尖，不是两指中点；如果把左指尖位置误当作夹口中心， 即使日志显示“到位”，实际夹口仍可能离物体很远，导致夹空。

2.2 我们遇到的问题

现象

日志曾显示横向残差约 46 mm，但脚本忽略了这一误差并直接闭合， 结果物体高度完全没变，判定为失败（夹空）。

2.3 最终修正

  • 用两根手指的实际世界位姿计算夹口中心，不再依赖单个指尖或 panda_hand 原点。
  • 用模型已知的手指尖偏移 FINGER_TIP_Z = 0.045 还原真实指尖位置。
  • 要求位置误差小于 12 mm、方向误差小于 8°，持续稳定后才允许闭合。

3. 关节

3.1 概念解释

脚本最终控制的是机械臂与夹爪的关节目标。手指关节是位置指令，夹持效果由关节目标与驱动增益共同决定。 另外，仿真重启会使旧的关节句柄失效，必须等物理就绪后再创建对象，否则读取关节会报错。

3.2 我们遇到的问题

  • 上升途中夹爪松开：发送机械臂关节目标时，夹爪闭合目标被覆盖。
  • 关节读取报错：stop → play 重置仿真后，旧的机械臂对象不能再读关节。

3.3 最终修正

  • 每次发送机械臂目标时，强制保留夹爪闭合目标。
  • 新增初始化阶段：等物理句柄有效后，再创建机械臂对象与控制器。

4. 动力学参数

4.1 概念解释

手指关节只是位置指令；真正决定“夹多紧”的是驱动刚度、阻尼、最大出力等动力学参数。 若参数过小，即使指令为完全闭合，物体仍会在抬起后滑落。

4.2 我们遇到的问题

现象

夹住后能抬起一小段，随后物体从指间滑脱。增大夹持指令后仍有缝隙，说明不是位置问题，而是出力不足。

4.3 最终修正

  • 闭合目标设为完全闭合：GRIP_CLOSE = 0.0，使指令饱和。
  • 放大手指驱动增益： GRIP_STIFFNESS_MULT = 20.0、GRIP_DAMPING_MULT = 10.0、GRIP_EFFORT_MULT = 5.0。
scripts/grasp/19d_grasp_side.py · 手指驱动增益放大

GRIP_DAMPING_MULT = 10.0

def boost_gripper():
    kp, kd = art.get_dof_gains(dof_indices=grip_idx)
    eff = art.get_dof_max_efforts(dof_indices=grip_idx)
    art.set_dof_gains(
        stiffnesses=flat(kp) * GRIP_STIFFNESS_MULT,
        dampings=flat(kd) * GRIP_DAMPING_MULT,
        dof_indices=grip_idx,
    )
    art.set_dof_max_efforts(flat(eff) * GRIP_EFFORT_MULT, dof_indices=grip_idx)

5. 抓取位姿

5.1 概念解释

抓取位姿指夹爪到达的位置与朝向，决定物体能否卡进夹口。 侧抓要求：接近方向水平、开口轴竖直，并且抓点要从物体边缘向内推进足够深度。

5.2 我们遇到的问题

  • 目标点算错：曾用半宽再除以 2，导致抓点远离物体边缘。
  • 坐标变换不一致：位置转为基座坐标，姿态却没有同步转换，导致接近方向偏转约 90°。

5.3 最终修正

  • 抓点直接由 bbox 的 min/max 计算近侧边缘，不再重复减半。
  • 构造侧抓姿态：工具 z 沿接近方向，工具 y 竖直；再把夹口中心目标转为模型左指尖目标，并统一做坐标系转换。
  • 咬合深度最终成功值：SIDE_INSET = 0.06。

def setpoint(pos, quat):
    """Convert the jaw-centre pose to the model's left-fingertip pose."""
    hand_quat = Gf.Quatd(float(quat[0]), Gf.Vec3d(*map(float, quat[1:])))
    pos = np.asarray(pos, dtype=np.float64) + np.asarray(
        hand_quat.Transform(Gf.Vec3d(0.0, MODEL_FINGER_OFFSET, 0.0)))
    tip_quat = hand_quat * Gf.Quatd(0.0, Gf.Vec3d(0.0, 0.0, 1.0))
    quat = (tip_quat.GetReal(), *tip_quat.GetImaginary())
    pos = world_to_base(pos)
    quat = world_quat_to_base(quat)

6. 任务约束

6.1 概念解释

本次任务是“夹住并稳定抬起”，不是“碰一下就结束”。 因此必须保证真正到位才闭合，判定前保持足够时间，且判定后继续保持夹紧。

6.2 我们遇到的问题

  • 提前闭合：缓速接近尚未走完，手臂只跟上中途目标就进入 close，导致夹空。
  • 判定过早：保持 15 步（约 0.25 s）就判定成功，随后掉落仍算成功。
  • 判定后放爪：结束阶段主动松爪，导致物体掉落。

6.3 最终修正

  • 必须完成缓速接近并稳定后，才允许闭合。
  • 判定前保持 JUDGE_HOLD = 90（约 1.5 s），避免误判。
  • 判定后不松爪，保持最大夹紧。

7. 最终参数与运行方式

参数最终值作用
SIDE_INSET0.06抓点自边缘向物体内部推进的距离，决定咬合深度
SIDE_Z_FRAC0.35抓点高度占物体厚度的比例，避免接近时刮顶
APPROACH_STEPS / SETTLE_STEPS180 / 30缓速接近时长与到位后稳定步数
TCP_POSITION_TOL0.012夹口中心允许的位置误差（米）
TCP_ANGLE_TOL_DEG8.0夹口方向允许的角度误差（度）
GRIP_CLOSE0.0手指完全闭合指令，使夹持力饱和
GRIP_STIFFNESS_MULT / DAMPING / EFFORT20 / 10 / 5手指驱动增益放大倍数
JUDGE_HOLD90判定前保持步数，避免“刚夹住就成功”的误判

运行方式

在 Isaac Sim Script Editor 中打开 scripts/grasp/19d_grasp_side.py → Run。 脚本自动启动，无需手动调用 _fsm.start()。可通过 _fsm.stop() 停止。
