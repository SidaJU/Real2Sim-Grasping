# Lesson 04 · 训练零更新的诊断，与 Real2Sim 的边界

> 阶段：T6（mask 训练与量化闭环）
> 这一课记录三件事：一个高效诊断技巧、一个框架语义陷阱、以及一个关于
> "仿真特权"如何让实验失去意义的项目级反思。

---

## 1. 一句话总结

两轮 masked 训练后，模型所有高斯的 opacity **仍然精确等于初始值 0.100**——
训练没有发生。根因分两层：

1. **直接原因**：初始点云来自真值深度反投影，形状答案已给，loss 天然极小，
   梯度不足以驱动任何可见的参数更新；
2. **叠加原因**：mask 语义反了（nerfstudio 中 mask=1 是"排除"不是"保留"），
   物体被排除、只训练白墙，loss 秒归零。

---

## 2. 高效诊断技巧：查参数是否等于初始值

遇到"训练无效"类问题，第一件事不是调参数，而是**读 checkpoint 验证训练是否发生**：

```python
import torch
ck = torch.load(ckpt_path, map_location="cpu", weights_only=False)
sd = ck["pipeline"]
op = torch.sigmoid(sd["_model.gauss_params.opacities"]).cpu().numpy()
print(op.mean(), np.median(op), op.max())
# 全部等于初始值(0.100) => 训练零更新，别再浪费时间调参了
```

| 诊断结果 | 含义 | 下一步 |
|---|---|---|
| opacity 分布**变了** | 训练在发生 | 查质量（loss 曲线、渲染） |
| opacity **恒等于初始值** | 训练未发生/零梯度 | 查 loss 是否为 0、mask 语义、数据是否喂对 |

同理适用于任何可训练模型：**初始值 vs 最终值的逐参数对比，是"训练是否发生"
的最强证据，比任何间接现象都硬。**

## 3. mask 语义陷阱（nerfstudio）

### 官方实现（splatfacto.py:707-715）

```python
if "mask" in batch:
    gt_img   = gt_img   * mask     # mask=1 保留，mask=0 置黑
    pred_img = pred_img * mask
Ll1 = torch.abs(gt_img - pred_img).mean()
```

被 mask 置黑的区域：gt=0 且 pred=0 → 差值恒 0 → **零梯度贡献**。

### 我们踩的两遍

| 版本 | mask 内容 | nerfstudio 理解 | 结果 |
|---|---|---|---|
| 第一版 | 物体=白(255)，背景=黑(0) | 物体参与，背景置黑 | 训练发生但更新极微（loss 本来就小） |
| 第二版（以为语义反了） | 背景=白，物体=黑 | **背景参与，物体被排除** | 只训白墙，loss 秒归零，参数完全冻结 |

**教训**：mask 类 API 的语义（1=保留 还是 1=排除）每个框架都不同，
**必须读源码确认**（`splatfacto.py` 的 `get_loss`），不能靠猜。第二版的
"反向修正"是在没有证据的情况下推翻第一版——错上加错。

## 4. 更深的根因：初始点云的"仿真特权"

### 现象链

```
初始点云 = 真值深度反投影（99 帧 × 像素 → 世界点）
        → 形状/纹理天生正确（彩色复印机扫出来的盒子）
        → 初始渲染已匹配 GT → loss ≈ 0
        → 梯度 ≈ 0 → 训练 30000 步 ≈ 0 步
```

用户在 viewer 中观察到"盒子从一开始就形状正确"——**那正是初始点云本身**，
不是学习成果。opacity 恒 0.100（未训练值）是铁证。

### 为什么这是个问题

我们最初的项目目标是验证：**"只用 RGB 照片，能否重建出可抓取的资产"**。

但当前管线里：

```
RGB（给了） + 真值深度（也给了，做了初始点云 + GT mesh）
```

形状的答案已经通过初始点云喂给了模型——**"重建"环节名存实亡**。
3DGS 训练变成了对已有答案的"精修"，而精修量小到测不出来。

### 真实世界没有这个特权

```
真实机器人：只有 RGB 照片
  → 初始点云只能靠 COLMAP 从照片估计（粗糙、含外点、需要标定）
  → 3DGS 真正需要"学"：把粗糙初始化精化成准确形状
  → 这才是有意义的重建
```

## 5. 目前诚实量化过的数字

| 产物 | 质量 | 说明 |
|---|---|---|
| GT mesh（真值深度 TSDF） | **0.2 mm**（vs YCB 尺寸） | 精度上界，可抓取资产 |
| 3DGS mesh（随机初始化，无 mask） | **Chamfer 35.75 mm** | 唯一一次真·RGB 重建的诚实数字 |
| masked 训练 × 2 | opacity 恒 0.100 | 训练未发生（本课主题） |

**35.75 mm 难看，但它是唯一真实测量的"RGB-only 重建"结果**——
其余两次训练因为初始化/语义问题没有产生有效模型。

## 6. 如果要做出有意义的 3DGS 重建（后续方向）

按优先级：

1. **初始化去作弊**：用 COLMAP 从 99 张 RGB 估计初始点云（不用真值深度）。
   这让"重建"真正发生——模型必须从粗糙初始化学出形状。
2. **物体抬高 + 相机拉近**：物体占画面 9.2% → 18%+（面积 ∝ 1/r²），
   提高有效监督密度。
3. **背景纹理**：给桌面/背景贴纹理，提供多视角约束，抑制背景坍塌。
4. **锁定曝光**：渲染端固定曝光（当前靠后处理压到 2.66）。
5. **mask 语义已验证正确**：物体=白(255→True=参与)。
6. **改进 densify**：真值初始化下梯度小，可降低 `densify-grad-thresh`
   （但注意：真值初始化本身就该去掉，见第 1 条）。

## 7. 可复用经验

1. **opacity/参数恒等于初始值 = 训练未发生的铁证**（先验证这个，再调参）。
2. **mask 语义必须读源码**：splatfacto 里 mask=1 参与训练（乘法保留），
   且被 mask 区域是"gt 和 pred 同时置黑"→ 零损失贡献。
3. **两版相反的 mask 都零更新** → 说明问题不在 mask 方向，
   在更深层（本例：初始点云太完美导致无梯度）。
4. **仿真数据太好会杀死学习任务**：设计实验前先问——
   "真实场景里拿得到这个输入吗？"拿不到的（真值深度）不该喂给模型。
5. **诚实的坏数字 > 漂亮的好数字**：35.75 mm 的 Chamfer 虽然难看，
   但配合根因分析，它就是整个项目最有说服力的部分。
