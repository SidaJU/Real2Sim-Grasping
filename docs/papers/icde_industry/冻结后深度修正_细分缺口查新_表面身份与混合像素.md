# 冻结后深度修正：表面身份与混合像素的细分缺口查新

- 整理日期：2026-11-17。
- 关联记录：[冻结后深度修正的前期查新与纠正](新空白_冻结后深度图逐像素去偏.md)。
- 状态：**发现了主要近邻未直接覆盖的细分环节，但尚未确认领域级空白；不是开工建议或首创证明。**
- 本轮范围：原始论文的方法、局限及部分官方源码；不训练、不运行基线、不修改现有流程。
- 用户要求：先查清新颖性，再决定是否做；不以先导实验代替文献查新。

> 本轮没有新增“已确认无人研究”的结论。新增重点是：在遮挡边界，区分深度数值偏差、表面身份错误与像素覆盖混合。PAGaS、SwiftNDC 等没有直接给出完整的混合像素身份纠错机制；但 CHOSEN、传统混合像素立体重建及 Gaussian Blending 已覆盖重要组成部分，不能靠组合名称宣布空白。

## 1. 一页结论

### 1.1 不能继续声称的新颖性

| 宽泛主张 | 已有证据 | 裁决 |
|---|---|---|
| 冻结重建后逐像素改深度，再融合 | PAGaS；SwiftNDC；Fink 等人的可微深度精炼 | 不是空白 |
| 深度不可靠时选择另一候选，再迭代精炼 | CHOSEN；传统 PatchMatch | 核心思路不是空白 |
| 像素级从 Gaussian 贡献选择代表深度 | SparseGS mode depth；TSGS 首表面窗口 | 不是空白 |
| 每像素分别处理多峰，而不是整幅图共用阈值 | TSPE-GS 官方逐像素实验分支 | 已有公开尝试，不能称无人提出 |
| 原始深度可靠时保留，其他位置修正 | Perfecting Depth | 不是空白 |
| 同时估前景、背景深度与混合系数 | 传统 mixed-pixel stereo 的摘要已描述 | 不能作为新参数化主张 |
| 在像素区域内处理空间覆盖与遮挡混合 | Gaussian Blending | 已有直接方法，且有冻结模型 RGB 推理替换实验 |

### 1.2 新增的细分问题

**不是“把深度往前挪一点”，而是：**

> 对冻结 GS 渲染的遮挡边界深度，识别它究竟对应真实前景、真实背景还是覆盖混合；在多视原始 RGB 同样存在边界混色时，如何纠正表面身份，而不让局部精炼被错误的单层颜色／可见性解释锁住？

这是本轮收敛出来的查新对象。**完整等价解法尚未检出，但检索范围不穷尽，传统混合像素先例的全文也未取得，因此暂不认定为空白。**

## 2. 三种错误必须分开

设前表面深度为 1.00 m，背景为 1.30 m；这些数字只用于解释，不是实测。

| 情况 | 输出例子 | 真正需要解决什么 |
|---|---|---|
| 同一表面的轻微数值偏差 | 1.01 m | 在正确表面附近连续精炼 |
| 深度贡献混合 | 1.15 m | 判断混合来自哪些表面，并明确输出语义 |
| 选错表面 | 1.30 m，却应返回物体前表面 | 先纠正表面身份，再细化该层深度 |

仅用 `D_corrected = D_initial - delta` 可以写出三种变化，但这种参数化没有解释如何区别三种成因。

还必须区分两种不同的“混合”：

1. **空间覆盖混合**：有限像素区域里，一部分子射线看到不透明前景，另一部分看到背景。
2. **沿射线透射混合**：同一子射线穿过透明界面，看见更深的表面。

两者都可能产生混色或多个深度贡献，却不应自动采取同一种表面提取规则。多个峰也可能来自浮点、错误几何或滤波，不必然都是物理表面。

**输出语义先于算法：**中心射线首次交点、整个像素的期望深度、各可见表面的深度与覆盖份额不是同一个量。不能把其中一种结果与另一种 GT 比较后称为“去偏”。

## 3. 主要近邻：已解决哪些，剩余什么

### 3.1 PAGaS：正确初始化附近的逐像素细化

来源：[arXiv:2604.22129v1](https://arxiv.org/html/2604.22129v1)，本轮定点读 §3.3–3.5、附录 C；技术判断限于这个版本。

- 每个有效目标像素一个一自由度 Gaussian，位置沿反投影射线变化。
- 颜色固定为目标像素 RGB，opacity 固定为 1；球形尺度随深度解析变化。
- 当前渲染按当前几何处理遮挡；另有用初始深度投影生成的上下文覆盖 mask。**不能把两种机制都概括成固定遮挡 mask。**
- 可使用外部前景 mask，但它不是前景／背景颜色解混。
- 推荐从上游 mesh 渲染较一致的初始深度；直接输入源深度也有实验，不能将其排除为竞争方法。

附录 C 的明确原句：

> “not to correct large errors or traverse long distances.”

**未直接覆盖的环节：**所读变量定义没有独立的前后层深度或像素覆盖变量；目标像素颜色若是混合颜色，固定该颜色与单层深度的解释是否会影响边界纠错，没有专门分解或验证。

后一句是机制分析，不是作者已经证明的边界失败。opacity=1 仍乘 Gaussian 核，并不代表投影足迹每处都完全不透明。

### 3.2 SwiftNDC：稀疏锚定的场景内仿射校正

来源：[arXiv:2602.22565v1](https://arxiv.org/html/2602.22565v1)，前一轮读 §3、§4.6；本文件沿用已建立的阅读结果。

- 输入经对齐的 VGGT／单目深度、像素坐标和视图序号。
- MLP 输出逐像素尺度与偏移；先场景级拟合，再逐视图优化。
- 以稀疏 SfM 深度锚点监督，校正后进行几何一致性过滤。

**未直接覆盖的环节：**没有在所读校正定义中显式识别边界层身份、前后景混色或覆盖份额。输出可大幅变化，不等于已验证能正确跳到另一物理表面。

不能因它的输入不是 GS，就否认其数值校正思路的相关性。

### 3.3 Fink 等：深度与轮廓坐标联合精炼

来源：[arXiv:2410.03861v2](https://arxiv.org/html/2410.03861v2)，本轮复核 §3.6–3.7、§5。

- 粗阶段使用 SfM 锚定的小型校正场。
- 局部阶段同时调整深度和图像坐标 `u/v`，使网格边贴合轮廓。
- 使用光度、边缘和 Poisson 式正则；遮挡处理及结构先验依赖初始深度边缘。
- 作者承认反光材质和初始输入错误仍构成限制。

**已占据：**“逐像素深度精炼＋更锐利边界”不是新的目标。

**未直接覆盖的环节：**所读方法没有显式前后层颜色／深度与面积覆盖联合模型。移动 `u/v` 不等于分解混合像素；但也不能据此推断其无法改善混合边界。

### 3.4 TSGS：逐像素首表面窗口

来源：[arXiv:2504.12799v1](https://arxiv.org/html/2504.12799v1)，前一轮读 §3.4、附录 A.4。

- 在每条射线的透射率限定区间内，选择渲染权重和最大的深度窗口。
- 对选中窗口内的 Gaussian 平面深度做归一化加权平均。
- 明确采用单层透明假设。

附录的原句：

> “currently assumes single-layer transparency”

**边界：**每像素窗口位置不同已经是像素级机制。最大权重窗口不是无条件的最早物理表面；这属于算法前提边界，不是该版本提供的普遍失败证明。

### 3.5 TSPE-GS：多层提取与像素异质性

来源：[arXiv:2511.09944v1](https://arxiv.org/html/2511.09944v1)，本轮复核 `Calculating the Peak Locations`；前一轮读融合与附录。

- 采样透射率对应深度，提取多个候选表面。
- 对每个视角在相同采样阈值下求像素平均深度，再检测峰对应阈值。
- 渐进融合：先融合外层并冻结相关体素，再处理内层。

选峰推导涉及原文假设：

> “p_p(d)=p(d+t)”

即同一表面类型的像素分布以深度平移关联。这个论证不能直接给任意权重、宽度和层数异质的像素提供保峰保证；**也不能推导为所有异质情况必然失败。**

更重要的是，官方源码已有逐像素分支。固定查验提交为 `cac432c`：

[`mesh_extract_opa_pixel.py`](https://github.com/nortonii/TSPE-GS/blob/cac432ccf3fd9ecccb8da9afd35c323e6b5b5665/mesh_extract_opa_pixel.py)

该版本已做逐像素曲线差分、平滑、候选位置检测和分组深度。函数名 `find_local_maxima_single` 的实际条件检测局部极小值；它作用于平滑后的差分幅值，不是直接检测物理深度 PDF 的峰。

仍有交互暂停，`depth_list`／`color_list` 没有填充，TSDF 循环不执行。**不能当成完整评估结果，也不能因其未跑完整就宣称逐像素思路不存在。**

## 4. 会否决细分新颖性的跨领域近邻

### 4.1 CHOSEN：表面候选选择不是空白

来源：[arXiv:2404.02225v2](https://arxiv.org/html/2404.02225v2)，本轮读 §3.1–3.2、§5。

原句：

> “each hypothesis should be evaluated independently”

方法从全范围或局部范围采样，结合空间传播，对候选评分，选一个深度，再迭代更新。多个正样本对应同一个 GT 深度附近，不是多个物理层。

**裁决：**把 GS 深度峰当候选，再使用相似的评分／迭代选择，不足以形成新机制。其所读输入和输出没有面积覆盖或透射层分解，但不能以此把通用深度精炼从强基线中剔除。

### 4.2 传统 mixed-pixel stereo：双深度与 alpha 早已有先例

论文：*Stereo Reconstruction with Mixed Pixels Using Adaptive Over-Segmentation*，CVPR 2008，DOI [10.1109/CVPR.2008.4587691](https://doi.org/10.1109/CVPR.2008.4587691)。

本轮搜索摘要明确描述：在边界混合像素处，估计 foreground opacity，以及前景、背景的颜色和深度。

**证据等级：只取得搜索摘要；作者 PDF 抓取失败，DOI 入口受验证页阻挡，未读取全文。** 不将摘要外的变量约束、透明条件、求解器或精度写成已核实。

这个先例足以构成重大新颖性警报：`foreground depth + background depth + alpha` 本身不能当新参数化。**在全文未核查前，不出具空白确认。**

### 4.3 Gaussian Blending：像素空间混合已经被直接研究

来源：[arXiv:2511.15102v1](https://arxiv.org/html/2511.15102)，本轮读方法、实验及局限；2025-11-19 版本早于本次检索日期。

- 直接处理像素区域内的空间遮挡与 alpha 混合。
- 关键区别是“先合成再积分”与“先分别积分再标量合成”不等价。
- 使用可移动、可变尺寸的二维窗口近似空间透射率，并更新其低阶矩。
- 有特定 Mip-Splatting／Analytic-Splatting 冻结模型替换 RGB 渲染 kernel 的实验。
- 所读版本没有报告冻结深度纠错、表面身份恢复或 TSDF 几何实验。

**裁决：**不能说像素区域覆盖混合尚无人修复；简单用新混合权重累积深度，也可能只是已有渲染器的直接扩展。RGB 改善不保证深度正确，但“没有深度实验”不自动产生新算法空白。

代码入口本轮未成功核实，不提供猜测仓库地址，也不声称作者未开源。

### 4.4 GLINT 与 Mip-Splatting

- [GLINT，arXiv:2603.26181v1](https://arxiv.org/html/2603.26181)：分开表示 interface、transmission、reflection，材质透明度与合成 opacity 不再同一参数。包含分阶段训练和冻结 interface 阶段，不是对任意冻结 GS 的直接深度补丁。不能将“最后有冻结”一概等同本路线。
- [Mip-Splatting，arXiv:2311.16493v1](https://arxiv.org/html/2311.16493)：3D 平滑与 2D Mip 滤波改善尺度和抗混叠。所读滤波定义不等于独立估出材料透明度与像素覆盖，也没有真实深度边界修复验证。

这些方法是相关的表示／渲染解法，而不是可以因“未做 TSDF”就排除的对手。

## 5. 剩余差异：本轮新增候选到底窄在哪里

拟查新的具体机制问题是：

> 在不改原始 GS 参数的条件下，利用多视原始观测和像素足迹证据，判断边界深度的错误层身份；将面积覆盖混合与沿射线透射分开解释，并在证据足够时修正相应表面深度，而不只取最强峰、平均全部贡献或依靠已错的初始化轮廓。

与主要近邻的有效差别应落在：

1. **明确的观测模型**：为什么某个混色观测不能直接作为单层表面的光度目标。
2. **身份判断依据**：为什么选择的候选是目标物理表面，而非强背景峰／浮点。
3. **覆盖与透射的可辨识条件**：在哪些观测条件下能区别，哪些情况下不能。
4. **有限证据下的行为**：缺乏证据时不能宣称恢复真值；可以保留候选或标为不确定，但拒绝本身不是新增贡献。

**以下均不能作为有效差异：**换一个后端、只加 `frozen` 限定、用残差表达输出、将多个已有模块顺序串联、把 RGB 渲染指标换成深度指标。

如果传统 mixed-pixel stereo 加现成假设选择器，或 Gaussian Blending 深度扩展，已经自然实现上述机制，应撤回候选，而不是继续增加限定词排除对手。

## 6. 可辨识性：不能靠更复杂网络补掉缺失信息

解释性的两项颜色模型为：

\[
I=c C_f+(1-c)C_b.
\]

只有一个 RGB 与一个混合深度时，前后颜色、深度及覆盖率通常有多种解释。这里的 `c` 是示例的空间覆盖份额，不直接等于 GS 学习 opacity 或材料透射率。

多视角、可见的纯前景／纯背景像素、相机约束或额外信息可能帮助消除歧义，但必须写清条件。视角相关反射、折射、共同模型错误会削弱这些信息。

没有这些条件时，“预测一个数”可以做到，“证明这个数是真实表面”不能据此成立。上游根本没表示目标层时，从现有贡献选峰也不能创造那层真实几何。

**下列查新阻塞解除之前，不建议启动本候选的实现或训练：**

1. 取得并核查 CVPR 2008 mixed-pixel stereo 的完整观测模型、更新规则与假设；确认差别是不是仅换了初始化来源。
2. 核查 Gaussian Blending 官方实现与深度相关扩展；判断改权重渲染深度是否已足够覆盖候选。
3. 检查分层深度、matting stereo、透明物体重建及边界精炼的后续工作；不只检索 GS 名称。
4. 核查 TSPE-GS 其他提取分支与后续版本；源码未完成不构成无人提出的证明。
5. 用输入、变量、证据、更新规则和输出逐项对照；如果只能说明“近邻没在 CoMe 上测”，否决新颖性。

文献查新可以判断已有机制是否覆盖；效果与成本留到选题通过之后。二者不混同。

## 8. 后续实验只用于有效性，不用于证明空白

本节仅供日后查新通过后使用，不是现在的开工清单，也不预设收益：

- 同一冻结模型比较原生深度、普通边界过滤、PAGaS、CHOSEN 适配及空间混合渲染器的深度扩展。
- 以正确表面附近的小偏差、背景层误选、边界面积混合分别统计；不能只报全图 MAE。
- 统一中心射线／像素区域输出与 GT 定义；报告细结构保留和全局准确度／完整度。
- 所有方法允许同样的原始图像、相机与缓存；不能给候选额外 GT 或额外传感器却不计成本。
- 分开报告来源信息提取、校正、融合成本；不将无效像素删掉后的误差下降当作恢复成功。

这些实验即使成功，也不单独证明 ICDE 适配。几何／渲染新机制更接近视觉领域；ICDE 仍需实质数据工程问题与应用证据。
